Actual execution evidence belongs under ignored `.local/captures/`, must use visible windows, and must be embedded in chat for the remote user. Synthetic tests do not replace game acceptance. Final binaries must disable the app-only virtual-controller fixture. Never bundle the user's ROM, extracted original assets or private saves in public source artifacts.

Future selectable roster/team/flag/kit packages are a parallel research and planning workstream. Their implementation has its own compatibility and save-isolation requirements; see `docs/research/roster-database.md`, `docs/research/team-visual-assets.md` and the package design proposal once available.
