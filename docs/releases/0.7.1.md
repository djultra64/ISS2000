# Version 0.7.1 — release preparation

Original project work and direction: **djultra64**.

**Status: In development... SO-MANY-ALIGNMENT-ISSUES!**

This patch corrects enlarged sprite sampling and duplicate translucent borders.
It is being prepared for Linux and Windows x86-64. Publication and Windows
compilation are pending; this preparation record does not claim either succeeded.

## Changes

- Preserve the selected POINT texel at fractional enhanced scales. This removes
  the Weather/Clear cuts and preview black lines in Stadium Select, and the
  white central join in End of 1st Half.
- Remove duplicate coverage from the verified one-cycle score-panel repair
  strips. The translucent top border no longer has bright marks above flags.
- Rebuild the corrected fragment shader variants together with their consumer,
  keeping generated byte arrays and their lengths consistent.

Original filtering remains the default. The legacy Bilinear option remains
available; Super-xBR is a separate, unimplemented proposal. Additional European
ROM revisions are recorded as a backlog and are not newly accepted by this build.
