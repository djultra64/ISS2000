# Version 0.7.1

Original project work and direction: **djultra64**.

**Status: In development... SO-MANY-ALIGNMENT-ISSUES!**

A sprite-alignment patch for Linux and Windows x86-64. Version 0.7.0 remains
available separately; existing portable folders and user data are preserved.

## Changes

- Preserve the selected POINT texel at fractional enhanced scales. This removes
  Weather/Clear cuts and preview black lines in Stadium Select, and the white
  central join in End of 1st Half.
- Remove duplicate coverage from the verified one-cycle score-panel repair
  strips, eliminating bright border marks above the flags.
- Rebuild all corrected fragment variants together with their consumer so
  generated byte arrays and their lengths agree on both platforms.

Original filtering remains the default. The legacy Bilinear option remains
available; Super-xBR is a separate, unimplemented proposal. Additional European
ROM revisions remain a backlog and are not newly accepted by this build.

## Validation and remaining issues

The correction source passed 522 automated tests with 12 expected skips. The
storage-export preflight was then corrected to compile the complete production
translation unit instead of an inline callback fragment that is not a separate
production file. That corrected test passes on Linux and Windows; no storage
behavior was changed. Final product changes after the Linux GPU comparisons
are limited to the 0.7.1 version/startup metadata.

Linux GPU comparisons at actual 1920×1080 and 3840×2160 covered Stadium Select,
the live scoreboard and End of 1st Half. More menu coverage, failing controls
and exact comparison identities are recorded in [the resolution audit](../research/pal-resolution-audit.md).
Both final builds compiled successfully. Every Linux 49 / Windows 51 portable
manifest entry matches; fresh data is empty and both ZIP CRC checks pass.
Windows includes 43 authentic project/dependency notices and six selected DLLs.
The final Windows executable validates the supported ROM with native exit 0.

The exact final Windows package rendered the title screen on the RTX 2060.
The preceding build also reached the attract-mode match before the internal
version-tuple-only rebuild. The logged harness uses a separate never-switched desktop and dummy audio; this
is not Windows audio acceptance. A normal window-close request did not finish
in that hidden environment, reproducing the limitation documented for 0.7.0.
Only the owned disposable test process was cancelled. Do not claim normal-exit
or full interactive Windows acceptance from this bounded smoke check.

Goal Kick transient alignment remains unverified. Goal-replay effects, some
overlay entrances, full game-mode completion, sustained 120 fps and every
physical controller family require further testing. This is not an accepted
1.0 release.

## Installation and compatibility

Download the ZIP for your operating system, verify it against
`SHA256SUMS-0.7.1.txt`, and extract the complete folder to a writable location.
Run `launch.sh` on Linux or `iss2000.exe` on Windows. Back up the previous
`data/` folder before migrating settings or saves.

Use your own Europe English/German revision 0 ROM. Canonical SHA-256:
`6ce6739b8ead149857c9442178a1ecd9b7f6d15b93a582c7208ca85d493817bf`.
Other revisions are not interchangeable. Linux requires x86-64, Vulkan,
GLIBC 2.38 and GLIBCXX 3.4.32 or newer. Windows requires x86-64 Windows and a
Vulkan-capable GPU with suitable drivers. No ROM or pre-existing saves are
packaged.
